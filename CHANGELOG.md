# Changelog

All notable changes to PostalPlan will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-13

### Added

- PLI and RPLI premium, maturity value, bonus and net-gain calculator.
- Support for 12 Postal Life Insurance and Rural Postal Life Insurance policies.
- Monthly, quarterly, half-yearly and yearly payment options.
- Official annexure-rate matching with clearly labelled indicative estimates when a matching row is unavailable.
- Detailed premium, rebate, GST, bonus and projected-return breakdowns.
- Downloadable PDF planning quotations generated on the user's device.
- Side-by-side policy comparison engine:
  - PLI policies can be compared only with other PLI policies.
  - RPLI policies can be compared only with other RPLI policies.
- Individual, search-friendly information pages for every supported policy.
- Practical PLI and RPLI policyholder checklist.
- Calculator customer guide and frequently asked questions.
- Privacy and technology transparency page.
- Public source-code verification and contribution information.
- Responsive layouts for desktop and mobile devices.
- Sitemap, canonical URLs and structured metadata.

### Privacy

- Calculator values are processed within the active browser page.
- No application database, user-account system or calculator-submission API is used.
- PDF quotations are generated locally with jsPDF.
- Hosting and third-party request-log limitations are explained transparently.

### Documentation

- Added project overview, supported-policy list and technology stack.
- Added installation and local-development instructions.
- Added contribution guidance and official India Post references.
- Added accuracy, independence and insurance-planning disclaimers.
- Licensed the project under the GNU Affero General Public License v3.0.

### Important notice

PostalPlan is an independent educational and planning tool. It is not affiliated with or operated by India Post. Estimates are not official quotations. Confirm eligibility, premiums, bonus rates and policy benefits using current India Post documentation or an authorised representative.
